# 成交规则

每局 2～7 人，最多五轮。全员报价后同时揭晓，未成交时进入下一轮。

| 轮次 | 成交条件 |
|---|---|
| 第 1 轮 | 唯一且非零的最高价 ≥ 第二高价的 2 倍 |
| 第 2 轮 | 唯一且非零的最高价 ≥ 第二高价的 1.7 倍 |
| 第 3 轮 | 唯一且非零的最高价 ≥ 第二高价的 1.5 倍 |
| 第 4 轮 | 不成交，进入第 5 轮 |
| 第 5 轮 | 最高价成交；并列时在最高价玩家中等概率抽取，全员报零也适用 |

成交者支付该轮报价，获得整个箱子，盈亏 = 箱内总价值 − 成交价；其他玩家盈亏为 0。

`state` 的 `settlement` 包含：

| 字段 | 含义 |
|---|---|
| `winner_id` | 获箱者 |
| `paid` | 成交价 |
| `total_value` | 箱内总价值 |
| `profit` | 获箱者盈亏 |
| `payoffs` | 各玩家盈亏 |
| `items` | 完整物品清单 |
| `tied_players` | 并列最高价玩家 |

# 专长重构：信息差、获取时机与经营取舍

日期：2026-10-27。状态：五种风格已实现为新房间默认规则；下表保留设计推导，实际次数与接口以末尾实施记录及 `../game-config.md` 为准。参数尚不代表平衡结论。

## 结论

建议把现有 26 种以品类为主的专长收敛为 5 种决策风格：速察、巡察、深研、筹划、择机。箱型继续决定物品先验，专长决定玩家如何获取和运用信息。卡牌保留为需要消耗资产的即时工具。

当前问题不是“同专长一定得到相同信息”：随机个体抽样仍会不同。但公开箱型让同一品类专长显得更划算，确定性统计和后期全量揭示又会把私人知识逐渐拉齐。单纯禁止重复选角不能解决这个结构问题。

专长必须改变实际可选动作、信息到达时机和机会成本；只给 Agent 写“激进”“保守”等性格提示，或者替它汇总所有人都能计算的公开报价，不会创造机制上的信息差。

## 共同的信息基础

1. 保留当前三件初始私人抽检作为所有人的基础，不让某个专长变成唯一能玩懂游戏的入口。
2. 取消与家具、军品、珠宝等公开箱型直接绑定的职业优势。调查题目可以涉及这些品类，但不把整类的免费持续鉴定作为专长身份。
3. 同专长玩家使用独立的私人样本、待选课题和调查分支，预期强度接近。允许事实答案巧合相同，不为制造区别而发假线索。
4. 新增的免费情报优先采用不指向具体物品的私人样本报告。报告说明采样方式和结论含义，但不给可与轮廓直接拼接的逐件品质、品类、坐标三件套。
5. 专长介绍、所选专长可公开；具体课题、答案、研究进度和筹备资源保持私有，人类观察者沿用现有独立权限。

这里的“私人样本”是后台冻结的一小组常规物品，不是整箱清单。例如课题可以询问样本中较高品质的占比属于哪一档，或较高品质物品是否更偏向大面积。具体题型、分档和样本大小尚未定稿，不能据此宣称已消除所有组合定价渠道。

不新增猜测总价真伪、检验报价是否超过箱价、精确价格均值等接口：它们会成为价格判断器或二分查询渠道。

## 五种候选风格

| 专长 | 第一版候选机制 | 玩家面对的选择 | 实际弱点 |
|---|---|---|---|
| 速察 | 第 1 轮可取得两条有限的私人样本报告；也可保留其中一条到第 2 轮。之后没有持续追加 | 是否依据较早优势争取提前成交，还是等公共线索验证 | 总信息量少于巡察，长局优势会被追上；不会因“速察”而被强制高价 |
| 巡察 | 第 1、2、3 轮各调查一个新的私人样本，覆盖尽量错开，每次只给浅层结果 | 是否持续扩大覆盖，并把有限卡牌用于补当前最重要的缺口 | 早期爆发弱，不能反复精修同一课题，也没有全箱补完 |
| 深研 | 第 1 轮选择一个课题并得到初步结论；第 2 轮可放弃一次即时信息机会锁定该课题，第 3 轮取得同一私人样本的补充结论 | 继续验证自己的关键判断，还是放弃研究转向当前机会 | 承诺后不能随公共线索任意改题，覆盖较窄，且可能来不及等到结果 |
| 筹划 | 第 1–3 轮可在取得基础报告与蓄积 1 点筹备之间选择；最多存 2 点，下轮起可用于增强一次普通侦察的样本覆盖 | 把当轮信息机会变成以后更高效的调查，选择何时花掉资源 | 必须真实放弃当轮机会；收益需要后续轮次与普通侦察配合。筹备不兑现现金、不跨局继承、不用于价格或身份鉴定 |
| 择机 | 第 2、3 轮各得到三道待查课题，只看问题描述，选一道后才获得答案 | 根据自己的初始抽检与当前缺口选择问题，减少无用重复 | 只有两次有限调查，强在选择而非数量；没有看到所有答案后再挑最有利的能力 |

“两条”“三次”“最多两点”都是候选参数。信息到得早本身就更有价值，不能用最终报告数量相同来推定平衡，也不能让速察在所有轮次都覆盖巡察的信息。

筹划与深研的区别：深研提前押注一个固定课题；筹划保留资源，稍后决定把调查能力用在哪里。择机的优势是问题选择，巡察的优势是稳定获得更多独立覆盖。

## 五轮暗拍中的必要取舍

- 所有专长在第 1 轮至少有共同初始抽检可用。长线专长的第一轮仍须有决策意义，不能只有“等第 5 轮”。
- 深研、筹划的核心收益应有机会在第 2–3 轮兑现。第 4–5 轮可以追加帮助，但不能成为长线专长的唯一有效阶段。
- 保留提前成交，不给长线专长额外的保局或否决成交能力。等待收益未兑现就是机会成本；角色选择不会改变他人合法成交的结果。
- 不能通过最高报价排名奖励更强情报而变相强迫冲价，也不能通过主动退出、报价 0 或超时自动赚取资源。运营优势来自放弃调查机会。
- 每轮最多一次专长选择；主动选择在本人报价前完成。未操作不自动花钱或消耗卡牌，不替玩家报价或退场。
- 房间创建时冻结专长规则；私人样本和题单在相应机制触发时确定并持久化。读 state、刷新、重连不重新抽题，不允许靠反复调用挑答案。

## 专长、卡牌与箱型的职责

| 系统 | 保留的职责 |
|---|---|
| 箱型 | 提供公开的物品分布先验，影响本局预期组成 |
| 专长 | 决定信息到达时机、调查方式和机会成本，形成长期策略 |
| 卡牌 | 用资产换取当下需要的额外调查，帮助弥补专长短板 |

定点鉴价继续遵守至少 25,000 金币、第 2 轮起、已观察单件目标的约束。专长不能用折扣、复制、免费使用或返还费用把这条成本门槛架空。普通卡的增强也必须受覆盖上限限制，不能等价变成免费全量鉴定。

## 仍须在定案前解决的风险

1. 目录改为“品质＋尺寸”非唯一后，加入品类、标签等仍有唯一价格组合。专长重构不能只检查输出有没有 price 字段。
2. 去掉直接价格字段、使用宽区间或私人样本，都不自动等于无法还原总价。需要审视一名玩家完整可得的信息及跨轮交集。
3. 不用“丢弃已知答案”作为成本，Agent 无法被要求遗忘。真正可执行的成本是没有获得本轮机会、消耗资源或锁定未来选择。
4. 不把公共报价的排名、均值等确定性计算包装成独占情报。Agent 本来就能自行计算；可以把公共事件作为触发条件，但收益必须是新的能力或私人信息。
5. 不用纯随机金额、随机假线索或按真实箱价动态拒绝查询来伪装不确定性。题型边界应事先明确，回答与触发状态本身也需要纳入信息披露检查。
6. 继续隐藏彩蛋及其存在性；抽样数量、补抽次数、题型是否可用等元信息也不能顺带指示彩蛋。
7. 当前实现会给逐件私有结果补充坐标。若引入非定位的样本报告，需要明确分离两种结果，避免通用序列化逻辑重新补齐被刻意省略的字段。

## 建议的下一步

用户已确认五种风格方向。后续优先比较同一箱型下的不同专长，以及相同专长下不同私人调查路径。

后续实际验收关注净收益、情报与卡牌支出、有效信息到达前对局结束的比例、私人信息重合程度、是否存在明显占优的固定选法。完整玩家流程由独立真实 Agent 执行，不指定它们必须采取某种报价风格。

## 实施记录

- 新房间默认五种风格，默认选择巡察。不再按箱型提供品类专长；旧房间继续使用冻结脚本和已有情报。
- 每轮进入时，为每人冻结三道课题及其隐藏样本；查询与选择失败不重抽。六道课题涉及品质、面积、交集、细长与小件比例，常规报告有放回抽样6次、分三档，不定位物品。深研沿原样本扩展至12次；筹划为普通卡额外附一份12抽样报告，不改变原卡费用、库存和次数。
- 速察两份不同课题报告，可牺牲当轮速度，将一份保留到第2轮并扩展到12次抽样；巡察第1–3轮自动报告；深研第1轮 start、第2轮 commit 或 take，仅承诺后第3轮交付；筹划第1–3轮 take（5次抽样）/bank/boost；择机第2–3轮 choose。主动行动每轮报价前最多一次，并需私人理由。
- API、CLI、双语手册、网页规则与授权观察已同步；私人状态不进入公共 SSE 和复盘帧。历史帧只展示到该轮已取得的情报及行动，不复制当前尚未完成的研究状态。
- 数据库5、快照12；已发布数据库3/4及快照10/11单向升级，保留账号、资产、旧规则与既有截止时间。
- 新增验证只涉及专长核心规则、权限和升级；没有新增界面测试。现有界面检查仅更新对旧默认目录的假设，旧冻结规则使用明确的发布格式样本验证。
